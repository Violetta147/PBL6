# Baseline source feature extraction

This package copies the previously audited mediapipe_extractor, normalization and handedness source from research/ai_audit unchanged. Hashes establish identity to those local audit copies, not byte-for-byte identity to remote source files (audit copies may have an extra final newline). Original notebooks, Drive files and checkpoints remain untouched. extraction_config.json is the extraction-only subset of the original preprocConfig.txt, transcribed to JSON to avoid adding a YAML dependency; dataset/temporal/QC/output/path sections are not consumed by extract_video and are omitted. Scientific extraction values remain unchanged. Hands complexity is the source/API default1; Pose1; FaceMesh processing off. Original source constructs the unused FaceMesh graph even when face processing is disabled; this behavior is preserved.

Run with ~/pbl6_edge_islr/.venv/bin/python and extract_fixed_clip.py via SSH. It reads the existing121frame fixed clip, matches its SHA256 and timestamp CSV, calls original extract_video, verifies feature keys/shapes/non-Inf and NPZ round-trip, then saves results/<UTC timestamp>/features_raw.npz, metadata.json, effective_config.json and capture_read_complete_seconds.npy.

Feature arrays preserve NaN for missing data, anatomical left/right assignment using pose wrists/fallbacks, wrist-centered hand coordinates, shoulder-centered body coordinates, palm relations, scales, masks, frame indices and original timestamps. features_raw.npz contains arrays only; source metadata is a separate JSON. This is not the original dataset writer/QC manifest format or a training-cache replacement. First3frames are included (this is feature extraction, not the prior118frame warmed benchmark).

AVI header says30FPS, but actual capture was about15FPS; source timestamps are intentionally unchanged index/30, with real read-completion timestamps saved separately. No claim these are sensor timestamps. Temporal/model adapters must use an explicitly checked time policy; do not infer a real4second gesture duration from the header.

No repair, resampling, input128D packing, classifier or recognition accuracy/parity validation yet. A new wrapper status or shape alone does not prove preprocessing equivalence to frozen dataset features. NaN is not replaced with0. Source normalization/hand-assignment math checks performed locally; actual native extraction is pending Pi execution. Pose0/Hands0 is only a speed candidate; baseline1/1 remains the reference until model outputs/validation support a change.
